# flyfishPhilo

An offline notebook for revisable thinking, inspired by Feiyu’s philosophical and self-distillation methods. It shares a method, not a person’s private archive or a trained model. Here **self-distillation** means turning experiences into explicitly scoped, revisable ideas or practices; it is not neural-network distillation.

**No installation:** download the repository ZIP, extract it, then open `index.html` in a modern browser. The workbench UI is in Chinese. Try the fictional reading circle: ending compulsory turn-taking helped one participant but left another waiting all evening for an invitation. Revise the practice; leave the larger question about freedom open. Download JSON before closing if you wish to continue. Markdown is a private reading copy, not a backup.

**Any text-based AI:** use [the English copy-and-paste prompt](any-chat.md). A model need not emit JSON or call tools. For agents that can, there are [versioned JSON envelopes, a standard-I/O CLI and local MCP](interop.md). No provider account or SDK is required. A proposal never endorses itself. Compatibility is a capability contract, not certification of every host or model.

**Why separate four things?** An observation is a record, a current principle is a human choice, a trial is a concrete attempt, and an unresolved question need not become a task. Connect ideas across questions with reasons. Keep abandoned ideas, objections and earlier wordings visible without granting them present-day authority.
