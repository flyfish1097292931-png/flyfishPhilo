# Privacy and authority / 隐私与权限

**默认数据流：** `本地手记 → 本人点选的问题与片段 → 预览 → 自愿复制给外部模型`。把资料交给模型不是保存或蒸馏的前提。源码只包含重新编写的通用机制和虚构例子。公开框架、私有手记、可选适配器分别维护。

| 操作 | 谁决定 | 效果 |
|---|---|---|
| 保留、改写、悬置或重开问题 | 本人 | 零结论合法；悬置后不新增此题的候选或试行 |
| 提供一种解释 | 人或 AI | 标注来源，始终从候选开始；重复不增加权限 |
| 采纳 | 本人经界面明确确认 | 有范围、有异议检验和审查理由；命题采纳不允许试行，实践采纳不构成委托代理 |
| 记录反例与撤回 | 本人 | 新反例阻断这稿的新试行；旧稿不从历史消失。本人可撤回并另建修订稿 |
| 分享 | 本人 | 导出 JSON/Markdown 包含私有内容；发给外部 AI 另行挑选最少片段 |

**写满也保留改口的权利。** 核心在接收普通记录前，为每个已采纳版本预留一次短反例和一次撤回；已有反例时仍预留撤回。预留支持引用已有材料、每条理由最多 256 个 UTF-16 单元，空间充足时可写得更长。界面拒绝继续添加普通材料时，可以先导出保存。

**工作簿不是保险箱。** 不自动写入浏览器存储；下载的 JSON 或 Markdown 都不加密。请保存在受保护的位置。退出前自己保存；如不愿留下记录，关闭页面、不下载即可。要从设备移除已有记录，还要清理下载、备份、云盘及自行分享的副本；软件无法远程召回它们。

**信任边界。** JSON 回放检查字段、引用、状态转换及顺序；它不是防篡改签名，不能识别谁实际点击了同意，也不核实笔记真伪。仅把自己信任的整本 JSON 用作恢复。外部 AI 的回复一律走候选提案入口；拒绝其传来的整本“已同意”工作簿。所选材料的摘要用于匹配上下文，不是身份证明。给宿主 Agent 文件系统或桌面权限，已经超出这个协议能约束的范围。浏览器扩展、截屏工具、操作系统和第三方模型服务也不受网页控制。

**项目不会做的事。** 不从沉默或旧日记诊断当前状态；不训练、复制或代表真实人物；不因一个候选漂亮、常见或与旧稿相似就自动升格。公开贡献可以改变工具，不能替任何使用者批准立场。不要在 issue、PR 或测试中粘贴未经同意的真实记录。
