# 方法：一句话怎样获得、又怎样失去分量

这套方法从飞鱼的哲学研究与自我蒸馏实践中抽取了两种动作：**保留一个活问题**，以及**说明自己凭什么暂时采用一个答案**。两件事可以分开发生。项目不提供飞鱼的私人画像，也不要求使用者接受他的世界观。

## 从自己的材料出发

先写一件有场景的事，而不是一个性格标签。把「周四被点到时，我划掉了写好的那句话」和「我讨厌社交」分开。前一句可以注明出处；后一句已经是解释。问一句：如果把人数、熟悉程度、发言顺序中的某一个换掉，哪一种解释会变？在还说不清时，留作念头就够了。

**四个位置，只有一个是当前规则：**

| 位置 | 放什么 | 不能据此推出什么 |
|---|---|---|
| 深层记忆 | 亲历、摘录、转述、AI 解释或注明为虚构的材料 | 写过、检索到、重复出现，均不等于今天同意 |
| 未坍缩区 | 问题、念头、悬置中的分歧 | 没有行动项，也不欠系统一个答案 |
| 当前内核 | 本人检验并明确采纳的有限命题或实践规则 | 采纳不是事实证明，不定义一个人的全部 |
| 执行层 | 本人登记的一次具体试行 | 模型认可、用户身份或外部操作权限 |

## 把直觉搭成立场

1. **发现旧词不够用的地方。** 两桌都说「可以跳过」，为什么其中一桌的人仍感到没有选择？
2. **给出一个最小区分。** 书面许可，与行使许可的实际代价。它是否让原来相同的两种情况得出不同判断？
3. **写出可争论的一步。** 写命题、适用范围、从材料到命题的理由，另留一种竞争解释。「我觉得对」不能代替中间那步。
4. **找不利材料。** 是反例（此稿不可照用）、限制（要写清范围）、本次未推翻，还是还分不出？选一个判断并解释，别以支持票数取胜。
5. **修订或停下。** 新版本指向旧稿；不同问题之间可声明支持、张力、依赖或区分，连线要写理由。也可以只留下未解的问题。

材料不必都是经验数据。概念分析可用反例，规范命题可用价值冲突，现象描述可用另一种同样说得通的读法。思想实验可以暴露一个区分，不能冒充一次观察；一次反驳只作用于被反驳的那一稿。

## 虚构示例里最值得看的转折

主持人以为「不点名」就给了大家自由。有人却在便笺上写：自己等了一晚上的邀请。于是旧规则被撤回，替换成「先选择参与方式，当场可跳过」。这支持在下一场试行一种不同的主持方式；它**没有**证明一个关于自由的普遍理论。那个问题在示例里仍是悬置的。

**手记不是人。** 兴奋、相似度和语言的漂亮，可以决定哪个念头值得再看一眼，不能决定哪条规则替人说话。只想生活、不想记录时，关掉它就好。
