# 方法：一次只问一个值得回答的问题

这个系统把苏格拉底式自我蒸馏做成 Agent 对话中的节奏：你给出一个问题，Agent 选择一个依赖你上一句的追问；你作答、改题、反问或停下。答案原文先作为来源保存。**候选是写给你复核的解释，不是从你的沉默、重复用词或问题里自动提炼出的内核。**

## 为什么一问一答

一串看似有关的问题会把探索变成既定的问卷：第三问可能还没有发生。把问题分成独立回合，才能看见后一句究竟回应了哪段原话，也让不回答成为真实选项。下一句追问的“证据锚点”必须来自你刚说的话，且 Agent 在它的问题里显示该原词。锚点约束跑题，**不证明问题公正、中性或不带引导**；发现它暗示结论时，你可以指出、改写或丢掉它。

一个可行的回合不是「发生了什么？这说明什么？你准备做什么？」三问，而是先问：

> 你能回忆一次最近发生的时刻吗？

如果你说：「讨论方案时主持人突然叫到我，我把已经写好的那句话删掉了。」那么 Agent 才可能问：「你把『已经写好的那句话』删掉时，先想到的是什么？」这个追问的锚点和转折点是刚才那句原话；你也可以说：「先不问我想到什么；我想知道为什么点名让我不舒服。」那是**问题在改写**，不是模型抓到一个缺陷要你解释。

## 必须保留的出口

- **不知道 / 不确定：** 停在这里；不知道的原因不是诊断线索。
- **跳过：** 不催促，也不记录拒绝理由。
- **先停 / 暂停：** 停止等待；下次明确回来时，可原样显示尚未回答的那一问。
- **反问 Agent：** Agent 让出回合。可以在回答完它后，由你决定是否回到之前的问题。
- **改题：** 开一个干净的论证片段；不再用旧题的回答证明新题的候选。旧材料仍是历史，不是假装没有发生。
- **到此为止：** 不提交立场、不生成待办事项也算完整结束。

## 问题什么时候变成候选

只有用户明确邀请整理后，Agent 才把已答的内容整理为一条可反驳的命题或实践。它必须提供四样东西：

1. 一句范围清楚的话，而不是一串性格特质；
2. 哪些情形可能适用，哪些还不确定；
3. 一个不依赖同一假设、也能解释现有话语的竞争解释；
4. 一种两种解释会给出不同判断的例子，或什么材料足以否定这条候选。

每条证据都要能在这轮对话保存的**用户回答原文**里逐字定位；Agent 提问、自己生成的解释、别的题下的材料，不能冒充作答。若引文不对，应修引文、重拟候选，或不写。

「帮我整理」表示提出候选，不等于「替我保留」。Agent 要把完整原文、论证边界和对手解释写出来，然后等待：你可以具体修改、留作候选、原样保留这一版或不做任何事。只有你清楚选择「保留这一版」，该版本才进入当前地图；系统把它标成**个人暂时保留**，不是真理证明、普世规则、诊断、永久画像或行动许可。要更换当前版本，先撤回旧版；旧证据与变更记录不删掉。

跨题连接也是一个待复核的命题：说明它与哪条**现在仍保留**的观点有关、是补充还是张力、凭什么连。撤回任一端后，连接应显示为过时，而不是暗中自动找一个替身。

## 四个位置仍然不同

| 区域 | 放置什么 | 所以不能做什么 |
|---|---|---|
| 深层记忆 | 本地记录的原话及回合出处 | 不等同于身份、立场、完整人生史 |
| 未坍缩区 | 一个待答问题、一条待检查候选、暂时的分歧 | 不自动解释成任务或答案缺失 |
| 当前内核 | 用户明确原样保留的、有限范围的一版 | 不升级为普遍事实或系统指令 |
| 执行层 | 本项目**不执行**任何外部行动；实践描述只是一条候选文字 | 不把“保留”升级成操作许可 |

## 可以自己动手试

安装后，在任一兼容 Agent 里启动：

> 我同意把本题和我的回答保存在本机手记中。我想一问一答地探一探：有些时候我为什么有话却不说？先不要帮我总结。

观察它是否只提一个问题、解释为什么这问接着你的哪一句。回答「不知道」，再看它是否真的停下。稍后重开该对话，查看它是否找回**同一条尚未回答的问句**而不是随机换一问。最后，即使聊得很好，也不要求它生成候选。继续使用是你的决定。
